# VibeCraft Product Context

## Users
- Primary: Non-technical people who have ideas for apps but can't code
- "我妈想做一个记账本" type users — zero programming knowledge
- They use phones more than desktops, but web is the starting point
- They need guidance, not blank canvases

## Brand & Tone
- Warm, inviting, human — not cold, not technical, not a dev tool
- Guiding voice: "Here's a starting point. Let's make it yours."
- Celebratory when things work; gentle when things break
- Never intimidating. Never a terminal. Never a code editor.

## Product Purpose
Turn natural language into working personal apps. Users pick a template, describe what they want changed, and get a usable app they can share. The AI is invisible — users don't need to know about models, tokens, or prompts.

## Anti-References
- Dev tools (no monospace as default, no dark-only terminal aesthetic)
- Code editors (no line numbers, no file trees, no diff views)
- "SaaS cream" — white backgrounds with purple gradients
- Geek culture — no "hacker" vibes, no command palettes

## Register
product

## Strategic Principles
- Templates over blank slates — always give a starting point
- Preview over code — users judge by what they see, never by source
- Undo over perfection — make it safe to try things
- Share over deploy — the goal is getting the app into someone's hands
